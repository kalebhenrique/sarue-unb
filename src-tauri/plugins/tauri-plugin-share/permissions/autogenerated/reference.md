## Default Permission

Permite compartilhar imagens usando a folha nativa de compartilhamento.

#### This default permission set includes the following:

- `allow-share-image`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`share:allow-share-image`

</td>
<td>

</td>
</tr>

<tr>
<td>

`share:deny-share-image`

</td>

</td>
</tr>
