## Default Permission

Permite ativar brilho máximo na tela e manter a tela ativa.

#### This default permission set includes the following:

- `allow-set-max-brightness`

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>

</td>

</tr>

<tr>
