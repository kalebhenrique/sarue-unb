## Default Permission

Permite consultar o status da conexão de rede atual.

#### This default permission set includes the following:

- `allow-get-network-status`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>

<td>

`network-status:allow-get-network-status`

</td>

</td>
</tr>

<tr>
<td>

</td>
